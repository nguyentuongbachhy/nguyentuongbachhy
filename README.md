## About Me

I'm a Software Engineer with a background in Artificial Intelligence, passionate about **backend engineering, distributed systems, and high-performance computing**.

I enjoy exploring how systems work under the hood, from algorithms and database internals to GPU kernels and neural architectures, with a focus on **performance, reliability, and efficiency**.

---

## What I Do

- **Backend Engineering:** Building scalable services, designing APIs, and exploring distributed architectures.
- **Systems & Performance:** Optimizing concurrency, memory usage, database access, and computational efficiency.
- **AI & Research:** Exploring efficient inference, sequential recommendation, and neural network architectures.

---

## Highlights

**Research · ACM RecSys 2026**

Co-first author of *CONGA: Continual Neural Gated Architecture for Long-History Sequential Recommendation*, accepted at ACM RecSys 2026 (Main Track).

**High-Performance Computing**

Building a from-scratch Rust and CUDA inference runtime, exploring custom GPU kernels, memory management, continuous batching, and efficient attention mechanisms.

**Backend & Distributed Systems**

Exploring service architectures, event-driven communication, database performance, concurrency, and system reliability through hands-on engineering.

---

## Currently Exploring

- **Distributed Systems:** Database internals, sharding, load balancing, and consistency.
- **AI Systems:** GPU programming, inference optimization, and efficient model execution.
- **Machine Learning Research:** Novel recommender architectures and long-term sequence modeling.
